## Requirement
xочу, чтобы пустые названия нельзя было сохранить при переименовании, чтобы пробелы по краям обрезались, пустые задачи не отображались ни в одном фильтре и не учитывались в счётчике открытых, а при попытке сохранить пустое название приложение показывало понятное сообщение.

## Acceptance tests
- AT1 (R1): Дано задача с id=1 и названием «Старое», действие — переименовать её в строку из пробела, `\t`, `\n`, `\r`, U+00A0 или их сочетаний либо в «  \t\u00A0  », ожидается прежнее название; при переименовании в «  Новое  » ожидается название «Новое», остальные задачи и длина массива не меняются, а в App.tsx при пустом названии вызывается `window.alert("Название не может быть пустым")`.
- AT2 (R2): Дано `seedTasks`, включая унаследованную задачу id=3, и пустая задача с `done: true`, действие — получить `visibleTasks` для фильтров all, open и done, ожидается отсутствие пустых задач для каждого фильтра, а для `visibleTasks(seedTasks, "all")` — id [1, 2].
- AT3 (R3): Дано `seedTasks` и другие наборы задач, действие — вычислить `openCount(t)`, ожидается равенство `visibleTasks(t, "open").length` для каждого набора и `openCount(seedTasks) === 1`.

## Non-goals
«Пустое название» — строка, в которой после удаления пробела, `\t`, `\n`, `\r` и U+00A0 ничего не осталось. Не делаем редизайн, не добавляем хранилище или зависимости, не меняем `createTask` сверх сохранения существующего обрезания названия; не меняем имена и сигнатуры экспортов из `src/tasks.ts` и не меняем `seedTasks`.

## Files in scope
Только `src/tasks.ts` и `src/App.tsx`.

## Definition of done
`npm test` и `npm run build` проходят; в diff реализации изменены только разрешённые файлы `src/tasks.ts` и `src/App.tsx` (тесты, спецификация и evidence — материалы задания); на экране отображается «Открытых: 1» и нет пустых строк.
